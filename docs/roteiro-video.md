# Roteiro do Vídeo — Apresentação do PortfolioHUB (~5 minutos)

**Dica:** deixe abertos antes de gravar: o repositório no GitHub, o site no GitHub Pages, o terminal (ou a aba de commits) e o LinkedIn.

---

## 1. Abertura — 0:00 a 0:30
**Tela:** site publicado (topo da página).

> "Olá, meu nome é Luiz Eduardo Paiva Costa, sou estudante de Engenharia de Computação no CEUB. Neste vídeo vou apresentar o PortfolioHUB, o repositório que criei para o desafio da entrega intermediária do Bootcamp I. O objetivo foi organizar meus projetos no GitHub, versionar com Git, publicar um site no GitHub Pages e integrar tudo ao LinkedIn."

## 2. Planejamento e estrutura — 0:30 a 1:30
**Tela:** página inicial do repositório no GitHub.

> "Primeiro eu planejei as seções do repositório. Separei em: a raiz com o site, a pasta `projetos`, dividida em `academicos` e `pessoais`, e a pasta `docs`, com a documentação e o relatório. A pasta `css` guarda o estilo e a `img` guarda as imagens. Assim fica fácil encontrar qualquer coisa."

*(Clique nas pastas `projetos/academicos` e `projetos/pessoais` enquanto fala.)*

## 3. Documentação — 1:30 a 2:15
**Tela:** README principal e depois o README de um projeto (ex.: IronStack).

> "Cada projeto tem o seu próprio README, com descrição, objetivos, tecnologias e como usar. O README principal explica o repositório inteiro, a estrutura de pastas, como o site funciona e o histórico de versões."

## 4. Versionamento com Git — 2:15 a 3:15
**Tela:** aba **Commits** do GitHub (ou `git log --oneline` no terminal) e depois **Tags/Releases**.

> "Todo o projeto foi versionado com Git. Usei commits pequenos e com mensagens claras, seguindo um padrão: `feat` para novidades, `docs` para documentação e `fix` para correções. A versão 1.0 tem o site inicial. Depois fiz alterações, como os READMEs dos projetos e os documentos, e enviei de novo, criando a versão 1.1. Aqui estão as tags marcando cada versão."

## 5. GitHub Pages — 3:15 a 4:15
**Tela:** site publicado; role a página devagar.

> "Este é o site publicado no GitHub Pages, feito só com HTML e CSS. Ele tem uma apresentação, a seção sobre mim, os projetos separados entre acadêmicos e pessoais, minhas habilidades, os documentos — incluindo o relatório final — e os contatos. Também funciona no celular."

*(Opcional: mostre rapidamente Settings → Pages para mostrar onde foi ativado.)*

## 6. LinkedIn — 4:15 a 4:45
**Tela:** seção **Projetos** do seu perfil no LinkedIn.

> "Por fim, deixei o repositório público e adicionei o projeto ao meu LinkedIn, na seção de projetos, com o link do site e do repositório. Assim, recrutadores conseguem ver meu trabalho diretamente."

## 7. Encerramento — 4:45 a 5:00
**Tela:** volta para o site.

> "Com esse trabalho aprendi a organizar um repositório, documentar projetos, versionar com Git e publicar um site. Os links estão na descrição do vídeo. Obrigado por assistir!"
