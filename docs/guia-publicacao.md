# Guia de Publicação — GitHub Pages, Repositório Público e LinkedIn

Troque `SEU-USUARIO` pelo seu usuário do GitHub em todos os passos.

---

## 1. Publicar o site no GitHub Pages

O projeto já está pronto: o `index.html` está na raiz do repositório, então não é preciso configurar nada no código.

1. Envie o projeto para o GitHub (veja o [guia de Git](guia-git/README.md));
2. No repositório, clique em **Settings** (Configurações);
3. No menu lateral, clique em **Pages**;
4. Em **Build and deployment → Source**, escolha **Deploy from a branch**;
5. Em **Branch**, selecione **main** e a pasta **/ (root)** → **Save**;
6. Aguarde de 1 a 3 minutos e recarregue a página;
7. Aparecerá a mensagem **"Your site is live at..."** com o endereço:

```
https://SEU-USUARIO.github.io/portfolio-hub/
```

8. Copie esse link e coloque no campo **About → Website** do repositório (ícone de engrenagem ⚙️ na página inicial do repositório).

> Se o site não aparecer: confira se o arquivo se chama exatamente `index.html` (minúsculo) e está na raiz, e veja a aba **Actions** para acompanhar a publicação.

---

## 2. Deixar o repositório público e gerar o link

**Se criou como Public:** já está pronto.

**Se criou como Private:**
1. **Settings → General**;
2. Role até **Danger Zone → Change repository visibility**;
3. Clique em **Change visibility → Make public** e confirme.

**Link de compartilhamento:** é o endereço do repositório:
```
https://github.com/SEU-USUARIO/portfolio-hub
```

**Melhorias opcionais (deixam o repositório mais profissional):**
- **About**: adicione uma descrição curta, ex.: *"Portfólio com projetos acadêmicos e pessoais — Bootcamp I"*;
- **Topics**: `portfolio`, `html`, `css`, `github-pages`, `git`;
- **Fixar no perfil**: no seu perfil do GitHub → **Customize your pins** → marque `portfolio-hub`.

## 3. Adicionar o projeto ao LinkedIn

### 3.1 Seção "Projetos"
1. Abra seu perfil no LinkedIn;
2. Clique em **Adicionar seção do perfil** → **Recomendado** → **Adicionar projetos**
   *(se não aparecer, procure em "Adicionar seção" → "Realizações" → "Projetos")*;
3. Preencha:
   - **Nome do projeto:** PortfolioHUB — Portfólio com versionamento Git
   - **Descrição:** sugestão abaixo
   - **Habilidades:** HTML, CSS, Git, GitHub
   - **Associado a:** seu curso/instituição
   - **Mídia → Adicionar link:** link do GitHub Pages e/ou do repositório
4. Salve.

**Sugestão de descrição:**
> Repositório criado no Bootcamp I para organizar meus projetos acadêmicos e pessoais com Git e GitHub. Inclui um site de portfólio em HTML e CSS publicado no GitHub Pages, documentação com README em cada projeto e versionamento com tags (v1.0 e v1.1).

### 3.2 Seção "Em destaque" (opcional)
Perfil → **Adicionar seção** → **Recomendado** → **Adicionar itens em destaque** → **Adicionar um link** → cole o link do GitHub Pages.

### 3.3 Link no topo do perfil (opcional)
Perfil → ícone de lápis da introdução → **Site** (ou "Link personalizado") → cole o link do repositório ou do site.

### 3.4 Publicação (opcional, mas ajuda na avaliação de "Integração")
Sugestão de post:

> 🚀 Concluí a entrega intermediária do Bootcamp I!
>
> Criei o **PortfolioHUB**, um repositório no GitHub para organizar meus projetos acadêmicos e pessoais, com versionamento em Git e um site de portfólio publicado no GitHub Pages.
>
> 🔗 Site: [link do GitHub Pages]
> 💻 Repositório: [link do repositório]
>
> #git #github #html #css #portfolio #engenhariadecomputacao

## 4. Vídeo no YouTube

1. Grave seguindo o [roteiro](roteiro-video.md) (ex.: com OBS Studio ou a gravação de tela do Windows: `Win + Alt + R`);
2. Acesse **youtube.com** → **Criar → Enviar vídeo**;
3. Título sugerido: *PortfolioHUB — Repositório com Versionamento | Bootcamp I*;
4. Em **Visibilidade**, escolha **Público** ou **Não listado** (não listado: só quem tem o link vê);
5. Copie o link do vídeo e coloque no `README.md` e no relatório.
