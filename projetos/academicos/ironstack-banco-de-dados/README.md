# IronStack — Sistema de Gerenciamento de Academia

> Projeto acadêmico da disciplina de **Banco de Dados**.

## 📌 Descrição
Exercício de modelagem de um banco de dados para uma academia fictícia chamada **IronStack**,
com cadastro de alunos, planos, instrutores e treinos.

## 🎯 Objetivos
- Praticar modelagem conceitual e lógica (entidades e relacionamentos);
- Criar tabelas com chaves primárias e estrangeiras;
- Escrever consultas SQL (SELECT, JOIN, GROUP BY).

## 🛠️ Tecnologias
- SQL
- Ferramenta de modelagem (ex.: brModelo / MySQL Workbench)
