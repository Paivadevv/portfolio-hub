# Artigo — Programação Funcional e Qualidade de Software

> Projeto acadêmico: artigo formatado nas normas ABNT.

## 📌 Descrição
Artigo que discute como conceitos da programação funcional — imutabilidade, funções puras
e ausência de efeitos colaterais — contribuem para a qualidade do software.

## 🎯 Objetivos
- Pesquisar e apresentar os principais conceitos da programação funcional;
- Relacionar esses conceitos com manutenibilidade, testabilidade e confiabilidade;
- Praticar escrita acadêmica no padrão ABNT.

## 🛠️ Ferramentas
- Node.js + biblioteca `docx` (geração do documento)
- Linguagem Clean (exemplos de programação funcional)
