# Automação de Inatividade em Python

> Projeto pessoal de automação.

## 📌 Descrição
Script em Python que monitora a inatividade do mouse. Se o mouse ficar parado por
**60 minutos**, o script fecha o navegador automaticamente e registra o evento em um arquivo de log.

## 🎯 Objetivos
- Praticar automação de tarefas com Python;
- Trabalhar com monitoramento de eventos e processos do sistema;
- Gerar arquivos de log.

## 🛠️ Tecnologias
- Python 3
- Bibliotecas: `pynput` (mouse) e `psutil` (processos) — *ajuste conforme seu código*

## ▶️ Como executar
```bash
pip install pynput psutil
python monitor.py
```
