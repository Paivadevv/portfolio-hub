# Política de Segurança

## Reportar vulnerabilidades
Use **Security → Report a vulnerability** (relato privado do GitHub) neste repositório. Não abra issue pública com detalhes de falhas. Projeto acadêmico: resposta em melhor esforço.

## Versões suportadas
Apenas o branch `main`.

## Regras do projeto
- Nenhum segredo (tokens, chaves, senhas) no repositório; se um vazar, **revogue imediatamente** e só depois remova do histórico.
- Sem dependências de runtime; mudanças em CSP exigem justificativa no PR.
